# Decisions & spec gaps

One line each: what, and why. "Spec gap" entries reconcile a mismatch between PRODUCT.md and the
authored lessons (or this build prompt) that should be folded back into the docs later.

## Environment & tooling
- Use Python 3.13 for the venv — the prompt requires 3.11+; the machine's default `python3` is 3.10.
- Line length 100; `ruff` per-file ignores limited to verbatim/dev files (schema, fixtures, tests, CLI B008).

## Vendor-neutrality
- "Vendor-neutral" is interpreted as: no networking-hardware / NOS vendor names anywhere. LLM
  provider names (anthropic/gemini/groq/ollama) are required by the prompt (env keys, provider
  chain) and are therefore allowed.

## Schema (§9)
- **Spec gap:** `card.redirect_line.maxLength` relaxed from 250 to 600. The authored redirect lines
  run ~340–360 chars; truncating would paraphrase authored content, so the bound was widened and the
  schema is otherwise verbatim from §9.
- **Spec gap:** `card.command_field_meanings` is `command -> {field -> meaning}` in §9, but the
  lessons author `command -> prose`. Converted mechanically as `{command: {"meaning": <prose>}}`.
- **Spec gap:** `chaos_options[].expected_effects` is an array in §9, but the lessons author one
  prose paragraph. Stored verbatim as a single-element array.

## Converter (mechanical MD -> YAML)
- `meta.verified_on` = `"UNVERIFIED — docker-sonic-vs:<branch>"` because every lesson still carries
  `[VERIFY-ON-LAB]` markers (not yet lab-verified).
- `observe.facts` = the schema-enum parser tokens literally present in the lesson's `## Observe`
  section (excluding the "Parsers available" preamble line). `key_fields` omitted (optional; not
  cleanly derivable without editorializing).
- `commands.baseline` = the first observe step's commands; `commands.per_step` = the Machine Summary
  command map minus `after_chaos`. The diff mechanism uses `after_chaos` as the before/after probe.
- `in_scope_subtopics` / `out_of_scope` split with a parenthesis-aware splitter (";" preferred, else
  ",") because lessons use the two delimiters inconsistently with the other inside parentheses.

## Runtime
- `demo_script.yaml` is a generated artifact (git-ignored); regenerate with `make demo-answers`.
  Absence falls back to the live model.
- Mock fixtures under `tests/fixtures/mock/` are dev artifacts generated by
  `scripts/gen_mock_fixtures.py`; one enabled anchor chaos per lesson has override fixtures so the
  before/after diff is non-empty offline.
- Experiment NL instructions map to a proposed command via a deterministic keyword table (no LLM
  tool-calling / auto-execution, per §4 and §10); execution still requires confirmation.
- Command spec slugs use a single `_` separator (`"leaf1: show mac"` -> `leaf1_show_mac`).
- CLI back-navigation is an in-session step-index decrement (navigation state lives in the
  orchestrator, per §5).
- Snapshot fact keys are prefixed with the source node (`leaf1:iface:Ethernet0:oper`) so probing
  the same table on both leafs (mtu/bgp lessons) can never collide in the diff.
- §5 universal keys (Esc/`b`/`q`) are realised as explicit `← Back` / `Quit` menu entries plus
  Ctrl-C — the questionary select widget does not expose custom key bindings.
- §5.2 endpoint 20's "confirm token" is a `confirm` boolean on the request body: the API is
  local/trusted, and the CLI is the surface that implements preview-then-confirm interactively.
- §8.6 "contradiction regexes built from facts" is simplified to the deterministic
  must-mention-a-changed-fact check plus the length cap; a value-level contradiction detector
  needs the eval harness first (§11 roadmap).
- `topo/configs/*.json` use the `Force10-S6000` hwsku — the canonical public platform identifier
  required by `docker-sonic-vs`; there is no vendor-free hwsku the image accepts.
- Session resume persists (lesson, step, budgets) to `~/.chaoslab/session.json` on quit;
  `chaoslab select` offers resume and `chaoslab run` shares the paused session's question budget.
- Measured reconvergence: `restore` reports `recovery_seconds`; on a live lab with
  `observe.measure_recovery` it polls (2 s interval, 30 s cap) until baseline facts return.
